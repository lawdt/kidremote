# KidRemote

Ограничение игрового времени на домашнем компьютере. Приложение висит в трее, показывает
в углу экрана таймер обратного отсчёта и блокирует экран, когда время кончилось. Время
выдаётся родителями с телефона через Telegram-бота.

## Как это работает

Родитель выдаёт **баланс минут**, а не окно времени. Баланс расходуется только тогда, когда
ребёнок действительно играет:

- сессия Windows разблокирована;
- компьютер не в спящем режиме;
- на переднем плане полноэкранное приложение;
- за последнюю минуту был ввод с клавиатуры или мыши.

Как только любое условие перестаёт выполняться, отсчёт замирает. Ушёл спать компьютер,
ребёнок свернул игру или отошёл — выданные минуты остаются на месте.

Telegram хранит недоставленные команды до суток, поэтому выданное время не теряется, даже
если компьютер в этот момент был выключен: после включения приложение заберёт всё, что
накопилось.

## Индикация

| Остаток | Цвет | Поведение |
|---|---|---|
| больше 5 минут | зелёный | ровное свечение |
| 5 минут и меньше | жёлтый | мигает раз в минуту |
| меньше минуты | красный | мигает раз в 5 секунд, на отметке в 1 минуту — короткий сигнал |
| отсчёт стоит | серый | плашка приглушена |
| безлимит | голубой | вместо цифр надпись «БЕЗЛИМИТ» |

Когда баланс исчерпан, на всех мониторах появляется экран блокировки. Игры при этом не
закрываются — после пополнения ребёнок возвращается ровно туда, где остановился.

## Управление из Telegram

Панель с кнопками (`/menu`) обновляется сама, поэтому остаток видно на телефоне в любой
момент без нажатий.

Кнопки: `+15` `+30` `+1 час`, `−5` `−15` `−30`, «Пауза», «Безлимит», «Заблокировать»,
«Обновить», «Родители».

Текстовые команды:

| Команда | Что делает |
|---|---|
| `+30`, `+1:30` | добавить время |
| `-15` | списать время |
| `=45` | выставить ровно |
| `/pause`, `/resume` | пауза: экран заблокирован, баланс не расходуется |
| `/free`, `/limit` | безлимит до отмены и возврат к лимиту |
| `/lock` | обнулить баланс и заблокировать немедленно |
| `/invite` | код для второго родителя |
| `/quit` | закрыть приложение на компьютере |

## Установка

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Запустите `KidRemote.exe` — он создаст файл настроек и откроет его.
3. Впишите токен в поле `botToken` и сохраните файл.
4. Запустите приложение снова.
5. Напишите боту любое сообщение — ваш чат станет родительским.
6. Второго родителя добавьте кнопкой «👪 Родители» → «Пригласить»: он отправит боту
   `/join КОД` и тоже получит панель управления.

Токен после первого запуска переносится в зашифрованное поле `botTokenProtected`, открытая
копия из файла стирается.

## Настройки

`%APPDATA%\KidRemote\config.json`

| Параметр | По умолчанию | Назначение |
|---|---|---|
| `idlePauseSeconds` | 60 | сколько секунд без ввода считать простоем |
| `requireFullscreen` | true | списывать время только при полноэкранном приложении |
| `warnSeconds` | 300 | порог жёлтого режима |
| `dangerSeconds` | 60 | порог красного режима |
| `overlayCorner` | TopRight | угол для плашки: TopRight, TopLeft, BottomRight, BottomLeft |
| `minimizeForegroundOnLock` | true | сворачивать игру при блокировке, чтобы её было видно |
| `blockHotkeysWhenLocked` | true | гасить Alt+Tab, Win и Alt+F4 на экране блокировки |
| `autostart` | true | запуск вместе с Windows |
| `allowTrayExit` | false | разрешить выход через меню в трее |

## Сборка

Нужен .NET SDK 8 на Windows:

```
dotnet publish src/KidRemote/KidRemote.csproj -c Release -o publish
```

Получится один самодостаточный `publish\KidRemote.exe` — среда выполнения внутри, ставить
ничего не нужно.

Тот же билд собирается в GitHub Actions (`.github/workflows/build.yml`), готовый `.exe`
лежит в артефактах сборки.

## Что приложение не умеет

Уровень защиты рассчитан на обычного ребёнка, а не на подростка, который всерьёз ищет обход:

- приложение снимается через диспетчер задач до следующего входа в систему;
- токен бота лежит на этом же компьютере, зашифрованный ключом учётной записи Windows —
  это защита от любопытства, а не от целенаправленного извлечения;
- `Ctrl+Alt+Del` перехватить нельзя, это ограничение Windows.

Если понадобится жёстче — состояние и логика уже отделены от интерфейса, поверх них
добавляется служба Windows, следящая за процессом.
